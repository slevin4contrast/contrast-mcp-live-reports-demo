About This Repository

This repository showcases the capabilities of the Contrast Security MCP (Model Context Protocol) Server. The reports and visualizations here are dynamically generated using real security data from Contrast Security's platform, demonstrating the power of integrating security intelligence with AI-powered analysis.

Each report provides interactive insights into application security, vulnerability management, attack detection, and more. These examples illustrate how the Contrast MCP Server can be used to create custom security dashboards and reporting solutions.

LIVE pages pull data on demand. Run node server.js and open these reports at http://localhost:3000. They call the same MCP tools Claude Code calls, reusing the token it already holds, so there is nothing to configure. Every other report is a static snapshot. See the README for details.
