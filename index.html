What this is

An MCP server is a set of tools an AI assistant can call on your behalf. The Contrast MCP server exposes 27 of them, covering vulnerabilities, third-party libraries, CVE exposure, live attacks, route coverage and application inventory. Connect it to Claude and you can ask questions of your own security data in plain language.

These pages are a different way of making the same point. Every one of them is an ordinary web page that calls those same tools directly and draws the answer. Each carries a panel showing exactly which tools ran, with what arguments, how long they took and how much came back, so the mechanism is visible rather than implied.

No AI tokens are spent here. MCP is a protocol, not a model. These pages talk to Contrast over HTTPS and no model runs, so refreshing a dashboard costs nothing in Claude usage. The AI was spent building the pages, not running them.

New here? Open What the MCP Can Do first. It lists every tool the server advertises, read from the server itself rather than written by hand, and lets you run the read-only ones against your own organization.

LIVE pages pull data on demand. Run node server.js and open these reports at http://localhost:3000. They call the same MCP tools Claude Code calls, reusing the token it already holds, so there is nothing to configure. Every other report is a static snapshot. See the README for details.
